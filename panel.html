Rôle Admin EnregistrementsRôle qui peut voir les enregistrements (configurez les permissions du salon)
ℹ️
Comment ça marche

1. Active l'enregistrement ci-dessus

2. Configure le salon d'envoi des enregistrements

3. Le bot rejoint automatiquement quand quelqu'un rejoint un salon vocal

4. L'enregistrement s'arrête quand tout le monde quitte le salon

5. Le fichier audio est envoyé dans le salon configuré

⚠️ N'oublie pas de configurer les permissions du salon pour que seuls les admins puissent voir les enregistrements !

💡 Commande /stoprecord pour arrêter manuellement un enregistrement
